# 刘耀声 · 项目作品集

[English](README.md)

我为制造和企业运营团队开发业务系统、数据报表和自动化流程，负责将业务规则转成可执行、可追踪的方案。项目涵盖库存与成本控制、基于 SQL 的企业报表，以及 Microsoft Power Platform 上的跨系统流程。

## 代表案例

| 案例 | 代表能力与交付证据 |
| --- | --- |
| [制造运营与 MRP](projects/mrp.md#中文) | 用 Express 和 MySQL 实现库存与材料成本追溯，云端试运行覆盖 9 个模块、26 个页面和 14 类岗位角色。 |
| [全球销售漏斗分析](projects/sales-pipeline.md#中文) | 用 SQL、DAX 和行级安全交付面向约 400 名用户的报表，覆盖 10 万余条销售机会数据。 |
| [员工离职流程自动化](projects/offboarding.md#中文) | 串联 11 个部门和 14 个 SAP 接口，将设备归还从 6 步简化为 3 步。 |
| [船舶靠港申报自动化](projects/port-call-automation.md#中文) | 用 Power Automate Desktop 将船运文件按顺序录入约十几个内部系统页面。 |
| [采购项目管理与分析](projects/procurement-savings.md#中文) | 用 Power Apps 和 Power BI 支持项目时间录入、进度展示和经营分析，一份追踪器导出包含 333 条数据记录。 |
| [AI 辅助地产合规材料初审](projects/document-review.md#中文) | 串联邮件收件、AI Builder 分类、材料完整性检查和合规初审。 |
